# Unit 1 – Fundamentals of Object Oriented Programming

### Program 1 – Smart Agriculture Sensor Monitor
Application for monitoring soil-moisture, temperature, and humidity sensor readings.

### Program 2 – Student Attendance Tracker
Application for storing student attendance details and generating an attendance report.

### Program 3 – E-Commerce Product Catalog
Application that maintains product ID, product name, price, and stock quantity using classes and static members.

### Mini Project – Smart Home Device Manager
Models smart devices such as lights, thermostats, cameras, and door locks with device ID, location, status, and last-updated time.

---

# Unit 2 – Inheritance

### Program 1 – Employee Payroll System
Payroll application for full-time employees, part-time employees, and interns using inheritance.

### Program 2 – Payment Gateway
Payment system supporting different payment methods such as credit card, UPI, and net banking.

### Program 3 – Vehicle Fleet Management
Fleet management application for trucks, delivery vans, and delivery bikes using a common vehicle hierarchy.

### Mini Project – Banking System with Account Hierarchy
Banking system containing a base `Account` class and derived `SavingsAccount`, `CurrentAccount`, and `FixedDepositAccount` classes.

---

# Unit 3 – Polymorphism

### Program 1 – CAD Shape Drawing System
CAD application that handles circles, rectangles, and triangles using a common base-class interface.

### Program 2 – Complex Number Calculator
Calculator that performs arithmetic operations on complex numbers using operator overloading.

### Program 3 – Input Validation Service
Validation system for marks, names, and payment amounts using function overloading.

### Mini Project – Media Player with Polymorphic Controls
Media player containing `Audio`, `Video`, and `Image` classes with operations such as `play()`, `pause()`, `stop()`, and `showDetails()`.

---

# Unit 4 – Files and Streams

### Program 1 – Student Record File System
Application that stores student records in a CSV-like text file and reads them to generate a report.

### Program 2 – Web Server Log Analysis
Application that analyzes web requests by IP address and identifies frequently occurring request sources.

### Program 3 – Binary File for Fixed-Size Records
Application that stores fixed-size metadata records in a binary file for compact storage and sequential retrieval.

### Mini Project – Library Book Management System
Library application that stores ISBN, title, author, category, and availability in a text file and supports adding, searching, issuing, returning, updating, and reporting.
